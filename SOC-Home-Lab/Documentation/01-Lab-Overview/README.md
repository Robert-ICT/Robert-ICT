
## Lab Overview

At the moment the home lab currently consists of 3 virtual machines with likely a 4th machine in the future for more indepth analysis and testing. The 3 machines are all running on my machine using VMware Workstation. The overall goal as previously stated is to create a small windows enterprise and perform SOC related activities, tests, etc.

## 3 Machines

### Ubuntu Server

This machine will be used for hosting Splunk. I chose Ubuntu server because it is incredibly optimized and runs without a graphical interface, leaving all the RAM and storage that would have been used up to instead be allocated towards making Splunk run smoothly.

### Windows server 2022

I chose Windows server 2022 because it is the only realistic option for creating an active directory.

### Windows 11

I chose Windows 11 because it is currently the newest version of Windows.
